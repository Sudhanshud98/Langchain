# LangChain Practice Repository

Hands-on LangChain learning repository containing foundational implementations, experiments, and practice projects focused on building LLM-powered applications using the LangChain ecosystem.

This repository serves as a practical workspace for exploring:
- Prompt engineering
- Chains
- Agents
- Memory
- Retrieval-Augmented Generation (RAG)
- Vector databases
- Document loaders
- Embeddings
- LLM integrations
- Output parsers
- Conversational AI workflows

---

## Overview

This repository contains basic to intermediate LangChain implementations created while learning and experimenting with modern LLM application development workflows.

The goal of the project is to build practical understanding of:
- LangChain architecture
- LLM orchestration patterns
- Retrieval pipelines
- AI application components
- Prompt workflows
- Agentic systems

The repository includes multiple standalone examples and scripts covering different LangChain concepts.

## Installation

### Clone Repository

```bash
git clone git@github.com:Sudhanshud98/Langchain.git
cd Langchain
```

### Create Virtual Environment

```bash
python -m venv venv
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```
